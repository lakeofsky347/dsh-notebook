# DSH Notebook

DSH 的笔记本研究工作台。可以从普通对话管理笔记本，也可以在插件界面选择已配置模型，直接对话、搜集资料、组织来源和生成 Studio 内容。模型接口与凭据由 DSH 管理。

## 使用方式

在侧栏或对话内打开「笔记本」，工作台会自动准备独立会话。底部输入框和自动构建表单共用按 DSH 提供方分组的模型菜单。方向键可浏览模型，Enter 选择，Esc 收回菜单并回到触发按钮。工作台会话可以独立使用，不需要先关联普通对话；会话记录、模型选择、模式和笔记本绑定保存在当前 profile 的 SQLite 资料库中。

单行顶栏显示当前笔记本，点击名称可切换、创建或重命名；「会话」管理工作台历史，「新对话」创建独立工作台，「更多」提供关联宿主对话、专注阅读和动效开关。来源、对话与 Studio 分成三栏，两侧可以收起并记住偏好；插件可用宽度不足 1000px 时使用两栏和区域切换，低于 760px 时仅显示当前区域。

- **自动构建**：点击来源栏或对话空态的「自动构建」，描述研究或学习目标，选择目标来源数（3 / 5 / 8）、模型，以及新建笔记本或补充当前笔记本。工作台驱动原生 Agent 拟定检索方向、调用 DSH 已配置的 `web_search` / `web_fetch`，将成功读取的候选网页正文直接去重入库，最后自动保存带来源引用、阅读顺序、自测题和资料缺口的学习导读。无需重新配置搜索 API key。
- **搜集构建对话**：适合自由研究或混合本地资料，例如「读取这些文件并补充相关网页」。模型可以创建笔记本、调用网页工具、导入 URL 或指定的本地文本文件、保存笔记。界面保留真实回复与最终资料，运行时通过轻量动效提示，可以随时停止。
- **资料问答**：打开已有笔记本并勾选来源，围绕资料提问。此模式不开放网页搜索工具，回答依据选中的资料；资料缺失时需要切换至搜集构建后补充。
- **普通对话管理**：在 DSH 对话中要求模型创建或打开笔记本、添加或管理来源、检索资料、生成产物。自动联网建库使用 `notebook_build`，支持 `prompt`、`title`、`targetSources`（1–12，默认 5）、`newNotebook`（默认新建）；混合本地资料的自由研究保留 `notebook_research`。用 `notebook_workbench_status` 读取真实研究状态、回复和已保存来源。研究会话会出现在工作台的会话列表中。
- **关联当前对话**：将工作台当前笔记本绑定给宿主中打开的对话。随后两处操作使用同一份资料；笔记本与来源状态通过界面轮询更新。

联网搜索依赖 DSH 已配置并可用的网页工具及搜索提供方。没有搜索提供方时，可以提供具体 URL 或本地文件路径；插件不会伪造搜索结果。原生 Agent 工具执行继续经过 DSH 的权限和审批流程，工作台不会自动批准被拦截的操作。

例如，在「自动构建」中输入：「帮我学习蒙特卡洛积分，优先大学讲义和原始论文，比较直接抽样与重要性抽样，整理入门阅读顺序和自测问题。」提交后，界面保留研究目标并以鲸尾动效提示运行；结束后显示实际收录数量、资料缺口和未完成项目，可以打开来源、学习导读或切换资料问答。

自动构建只收录当前研究搜索实际返回、并经原生网页工具成功读取的 HTTP(S) 候选。读取结果通过宿主最终 `tools/result` 事件保存，不重新下载、不把搜索摘要或模型总结冒充原文；PTC 程序子调用需等待外层成功。保留原始请求地址、最终 URL、获取时间和正文截断标记。重复 URL 复用已存版本，已取消勾选的来源保持关闭且不计入完成数量。来源目标是上限与完成标准，不承诺每次都能收集足额资料。

研究状态与证据清单持久化在工作台消息中；来源不足目标或导读失败会显示部分完成或失败，搜索与读取失败逐项展示。模型单纯声称“完成”不算成功。停止后保留已保存来源；宿主重启后将未结束的研究和导读标记为中断/失败，可以查看已有资料并重新发起构建，不会暗中继续联网。自动构建期间暂不允许切换笔记本、修改来源或并发启动另一轮研究。

自动构建在已保存且勾选的来源达到目标后停止采集，直接开始独立的导读生成。采集达到时间、步骤或模型限制时，如果已经保存可用来源，会尝试生成注明覆盖范围和失败原因的部分导读，整体仍标为部分完成；没有可用来源时不生成导读。用户主动停止或插件关闭时保留已保存资料，并停止后续生成。自由搜集构建对话使用相同的研究预算，但不自动套用来源目标或部分导读流程。

运行提示沿用 DSH 原生鲸尾动效，放在顶栏或当前详情标题的固定小槽位中，同一时刻只显示一处；空闲阅读时不显示。自动构建、资料问答、Studio 生成和练习同步都使用这一提示，不显示实时阶段、步骤、工具追踪或原始工具结果。正常回答仍可逐步出现，失败原因、停止操作和最终结果完整保留。系统开启「减少动态效果」、强制配色或关闭动效时，运行提示使用静态鲸尾。

空白对话中央展示取自 DSH 首页的粒子鲸。默认显示静帧，点按鲸形或用键盘聚焦后按 Enter、空格，会播放一次约四秒的跃动。出现对话或研究内容时，阅读区让给正文。来源、对话与 Studio 采用遵循宿主语义配色的三栏圆角岛屿表面，底部悬浮胶囊输入框在聚焦与运行期间沿边缘展示深海蓝单色流光。模式、区域和来源类型切换共用非对称弹簧滑动底片，连续点按可在移动中转向。Studio 用学习指南主卡和两列横向工具胶囊区分生成入口，下方列出已生成的内容；点击来源或已生成产物可在对应侧栏内原地展开并列阅读，点击引用自动联动左栏原文追光。系统开启「减少透明度」时，浮层切回实色。动效不使用 Canvas 或 JavaScript 绘制循环。素材归属见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 来源与 Studio

支持粘贴文本、HTTP(S) 网页、本地 `.txt`、`.md`、`.markdown`、`.csv`、`.json`、`.text` 文件，以及手动或工具创建的笔记。本地文件通过绝对路径读取，不是浏览器上传。可以查找来源、全选可用来源、查看保存的正文、重命名和删除来源；详情按需打开，支持 Esc 关闭并恢复焦点。助手回答可以保存为笔记；回答、学习指南、简报和报告中的 `[sourceId]` 只有匹配到当前笔记本的真实来源时才转换为可点击引用，其他标记保留原文。

HTML 导入使用 DOM 解析提取文字、标题与链接，移除脚本等非正文内容，不执行网页 JavaScript；依赖登录、动态渲染或反爬验证的页面可能无法完整导入。自动构建使用宿主读取结果，手动 URL 导入仍使用原有 HTTP 抓取。PDF、Word、音视频暂未提供解析。

模型通过 `notebook_source` 按页核查正文：`offset` 默认 0，`limit` 默认 6000、最大 12000，单位为 UTF-16 字符；用返回的 `nextOffset` 继续读取，`bodyLength` 和 `hasMore` 表示保存长度与是否还有下一页。分页只限制单次工具返回，资料库和来源详情保留已保存的完整正文。

选中的正文按段落和重叠窗口切片，使用支持中英文的 BM25 检索。未提供向量数据库或语义嵌入。Studio 用两列入口提供学习指南、简报、报告、闪卡、测验、思维导图、数据表，使用工作台选定模型，根据检索片段生成。导读与 Studio 取材覆盖明确主题和不同来源，并补足相邻段落；未命中关键词的来源提供明确标记的补充上下文，取材受字符预算限制。已生成内容单独列在下方，点击查看正文与状态。结果保存生成时的来源修订号，界面自动刷新完成或失败状态。学习指南、简报、报告采用文字预览；测验和闪卡采用交互练习；思维导图和数据表仍是 JSON 预览。

导读与 Studio 的独立模型请求会读取所选模型的上下文窗口，为回答和消息开销预留空间，再按来源均衡缩短证据片段；来源引用和元数据按最终片段重新计算。用户要求与笔记本说明始终完整保留。如果这些固定内容或必要证据仍放不下，会明确提示缩短要求、减少来源或更换模型，不发送注定超预算的请求。宿主未提供窗口信息时保留 `maxInjectChars` 的既有字符预算，不猜测模型容量。

### 测验、闪卡与错题重练

点击 Studio「测验」或「闪卡」使用当前工作台模型生成练习，完成后从已生成列表打开。测验默认 5 道单选题，闪卡默认 8 张；也可以通过 `notebook_generate` 的 `prompt` 指定数量（1–30）和范围。题目、答案、解释及来源引用经过结构校验后才标为完成，结构或引用无效会显示生成失败。结构校验不能替代对模型题目内容的核对。

- **测验**：选择一项并提交，先保存作答，再显示判分、正确答案、解释和来源。未提交时不显示答案或解释；已提交答案不能覆盖，可通过重新练习产生新记录。
- **闪卡**：先填写回忆内容（想不起时可留空），保存并翻面后查看答案与解释，再选择“记住了（自评）”或“再练一次（自评）”。这是学习者自评，单独标记，不等同于模型判分或已经掌握。
- **继续与历史**：练习队列、当前位置、每次作答、自评和时间都保存在当前 profile 的 SQLite 中。关闭详情或重新打开工作台会恢复已有练习；历史显示该产物最近 200 条记录，重新练习会保留此前作答。
- **错题重练**：按照每题最近一次完成的判分或自评，提取答错或“再练一次”的条目。测验点击“错题重练”，闪卡点击“待巩固重练”；重新答对或自评记住后移出当前待练队列，原来的错误记录继续保留；仅翻面不会记为掌握。
- **来源变化与旧产物**：来源修订或练习正文发生变化时，保留旧记录并提示重新生成，阻止继续按旧版本评分。旧 JSON 仅在答案含义明确且具有解释和有效来源时兼容；没有引用、缺少解释或答案格式含糊时，需要重新生成。

后台生成通知只报告练习数量和打开方式，不自动把答案发到聊天里。练习不触发额外模型判分；单选题按保存的标准答案判分，闪卡由学习者自评。当前没有自由文本自动评分、间隔复习或知识掌握度预测。

## 运行与数据

需要 Node.js ≥ 24.9.0 和 DSH `>=0.2.1-rc.5 <0.3.0`。通过 profile bundle 加载 `cordis.patch.yml`，客户端由宿主模块加载器注入 React。

资料默认保存在 profile 的 `plugin-data/dsh-notebook/library.sqlite`；也可用插件 `dataDir` 指定目录。已有资料库会自动增加工作台表，保留原笔记本、来源、产物和会话绑定。工作台的完整模型上下文由 DSH 原生 Session 记录；SQLite 消息是用于界面显示的投影。重启后续聊要求宿主仍能读取该 Session 的持久化日志；缺失日志时会明确报错，历史界面记录仍可查看。

主要配置包括 `maxNotebooks`、`maxSourcesPerNotebook`、`maxUploadBytes`、`maxWordsPerSource`、`chunkChars`、`chunkOverlap`、`topK`、`maxInjectChars`、`urlTimeoutMs` 和 `maxUrlBytes`。工作台按模式分别配置运行预算：

| 场景 | 时间预算 | 原生 Agent 步骤预算 |
| --- | --- | --- |
| 自由搜集构建与自动构建采集（`research`） | `researchTimeoutMs`，默认 900000 ms（15 分钟） | `researchMaxSteps`，默认 48 |
| 资料问答（`sources`） | `assistantTimeoutMs`，默认 180000 ms（3 分钟） | `assistantMaxSteps`，默认 24 |
| 自动构建导读 | 采集结束后单独计时，使用 `assistantTimeoutMs` | 独立模型生成，不占采集步骤 |
| Studio 产物 | 每个生成任务使用 `assistantTimeoutMs` | 独立模型生成 |

`assistantMaxTokens` 默认 8192，供原生工作台请求与独立生成使用。独立生成还会参考宿主路由的默认输出值；已知上下文窗口时，输出预算最多占窗口的四分之一，输入另留消息开销。`maxInjectChars` 默认 16000，`maxChatChars` 默认 32000。提高研究预算不会扩大模型自身的上下文窗口或取消上游搜索工具的超时限制。

搜集构建期间不再每步重复注入资料正文，自动研究目标只发送一次。工作台在完整工具结果已被来源入库逻辑处理后，使用宿主已有的工具结果裁剪服务缩短后续模型可见的长输出；隔离 preset 中的服务通过宿主公开 registry 解析。原生裁剪追加可回放的替换事件，保留原始 Session 日志与已保存来源，不删除历史，也不另挂一套自动压缩引擎。宿主没有该能力时跳过裁剪，真实存储错误仍会报告；工具结果投影仍保留在工作台记录中，界面不展示工具追踪。

## 开发与验证

```sh
npm ci --legacy-peer-deps
npm test
npm run dev
npm run test:ui
```

开发预览默认位于 `http://127.0.0.1:8765/dev/preview.html`，使用模拟宿主和模拟模型，不调用真实供应商。`test:ui` 自动启动临时本地服务与 Chrome，保存报告和桌面、窄屏截图至 `output/dev-smoke/`；可通过 `CHROME_BIN` 指定 Chromium 可执行文件。

`npm run preview:motion` 使用现有 Chrome 和 ffmpeg 录制当前界面动效，输出 6 秒 MP4、GIF 和截图至 `output/motion/`；`preview:particles` 作为兼容别名保留，可通过 `FFMPEG_BIN` 指定 ffmpeg 路径。录制使用开发模拟数据，不调用模型。

核心测试覆盖资料隔离、工作台持久化、中文检索、原生事件投影、工具管理与模式限制、模型选择、取消与恢复，以及接口行为。模拟宿主测试与浏览器预览不等同于真实 DSH 桌面验收或供应商模型调用。

自动构建新增测试覆盖最终原生搜索/读取结果到正文保存和引用导读的完整服务流程、无真实来源时的失败、权限路径内的 PTC 嵌套及并发结果、取消后不落库、导读生成中停止、失败/截断/禁用来源处理、并发启动冲突，以及数据库重开后中断产物收尾。

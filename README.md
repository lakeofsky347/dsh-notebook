# DSH Notebook 用户手册

DSH Notebook 是 DeepSeek Harness（DSH）里的研究和学习工作台。你可以把网页、本地文本和笔记集中到一本笔记本里，向选中的资料提问，点开引用核对原文，也可以在 Studio 生成学习指南、测验和闪卡。

## 安装和打开

- 使用 **DSH 0.2.1-rc.5 或更新的 0.2.x 版本**。下面以桌面版的 `desktop` profile 为例。如果你用独立的 Web profile，把命令中的 `desktop` 换成实际名称。独立部署使用 Node.js **24.9.0 或更新版本**。
- 在 DSH 的模型设置里配置至少一个可用的对话模型。使用「自动构建」还需要在 DSH 接入网页搜索和网页读取工具。

1. 打开过一次 DSH 桌面端后，完全退出应用。从发布页下载 `lks347-dsh-notebook-1.0.0.tgz`。[下载 v1.0.0 安装包](https://github.com/lakeofsky347/dsh-notebook/releases/tag/v1.0.0)
2. 在终端用 DSH 自带的 CLI 安装，把示例路径改成安装包的实际位置。

   ```sh
   dsh plugin --profile desktop add "/path/to/lks347-dsh-notebook-1.0.0.tgz"
   ```

   如果 macOS 终端找不到 `dsh`，默认安装位置里的 CLI 路径是 `/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh`。替换命令开头的 `dsh` 时，用引号括住完整路径。
3. 重新打开 DSH，在侧栏点「笔记本」。普通对话页面也有「笔记本」入口。首次打开会自动准备一条工作台会话。

### 从开发版升级

如果同一个 profile 之前通过本地仓库安装了旧的 `dsh-notebook`，先退出 DSH，备份该 profile，再用下列命令移除旧插件。随后按上面的步骤安装新版。新版会在同一个 profile 读取原有的笔记本库。

```sh
dsh plugin --profile desktop remove dsh-notebook
```

## 用现有资料开始

1. 点工作台顶部的笔记本名称，再点「创建笔记本」。如果还没有打开任何笔记本，来源栏也有创建入口。
2. 在来源栏点「添加来源」，选「文本」粘贴资料，或选「网址」「本地文本」导入已有资料，再点「加入来源」。
3. 勾选本轮要用的来源。在输入框底部选一个模型，切到「资料问答」，输入问题并发送。按 `Enter` 发送，按 `Shift + Enter` 换行。
4. 点回答里的引用查看保存的原文。想留下某条回答，可以点「保存到笔记」，它会出现在当前笔记本的来源栏。

可以先试这样一个问题。

> 请用三句话概括这份材料，再列出两条我应该回到原文核对的结论。

### 资料格式和管理

| 类型 | 怎么添加 |
| --- | --- |
| 粘贴文本 | 选「文本」，粘贴正文，按需填写名称。 |
| 网页 | 选「网址」，输入完整的 HTTP(S) 地址。插件保存提取到的正文。登录页、验证页和依赖脚本渲染的网站可能读不到完整内容。 |
| 本地文本 | 选「本地文本」，填写 DSH 运行机器上的文件绝对路径。支持 UTF-8 编码的 `.txt`、`.text`、`.md`、`.markdown`、`.csv` 和 `.json`。 |
| 笔记 | 点来源栏的「创建笔记」图标，或把已有回答「保存到笔记」。 |

PDF、Word、图片和音视频目前需要先转换成文本，再导入。来源搜索按名称筛选。点来源名称可以读正文、改名或删除，按 `Esc` 可以关闭详情。取消勾选会把来源排除在后续问答和生成之外，正文仍保存在笔记本里。

## 让工作台搜集资料

### 自动构建

在来源栏点「自动构建」，填写想研究的问题，选择模型和 **3、5 或 8** 个目标来源。默认新建笔记本。如果想补充现有笔记本，先打开它，再取消勾选「创建新的笔记本」。点「开始检索并构建」即可。

> 我想学会用 Python 的 TaskGroup 管理并发任务。请优先找官方文档，解释异常和取消如何传播，最后给我一份阅读顺序和几道自测题。

工作台会用 DSH 的工具搜索、读取和保存网页正文，并根据收录的资料生成学习指南。构建结束后，可以展开结果查看实际收录的来源和未完成项目，也可以点「打开学习指南」或「进入资料问答」。

能收录多少资料，取决于搜索结果和哪些网页能读到正文。重复网址只计一次，超过时间上限时会结束采集。点「停止」会保留已经保存的来源。遇到部分完成或运行中断，可以查看结果，再对当前笔记本补充资料。

### 搜集构建对话

如果已经有几个网址或文件，或者想分几轮指定方向，在输入框选择「搜集构建」，直接告诉模型要找什么、读哪些资料、保存到哪里。模型可以使用当前 DSH 提供的网页和笔记本工具，工具执行遵循 DSH 的权限与审批设置。手动导入网址和本地文本也可以在未配置搜索时使用。

「资料问答」会围绕勾选的来源作答。发现资料缺口后，可以先手动添加来源，或切到「搜集构建」补充，再回到「资料问答」。

## 在 Studio 生成内容和练习

先勾选来源并选模型，再点 Studio 里想生成的内容。如果有具体要求，可以先把要求写进输入框，然后直接点 Studio 的生成按钮。生成结果会保存在「已生成」列表，点开即可查看。

| 内容 | 适合用来做什么 |
| --- | --- |
| 学习指南、简报、报告 | 确定学习顺序、快速浏览要点，或按主题整理详细材料。支持点引用查看来源。 |
| 测验 | 默认生成 5 道单选题。提交后显示正确答案、解释和来源。 |
| 闪卡 | 默认生成 8 张卡。先写下回忆内容再翻面，也可以留空直接翻面。查看答案后选择「记住了（自评）」或「再练一次（自评）」。 |
| 思维导图、数据表 | 提取主题结构或表格数据。当前在 Studio 中以 JSON 预览。 |

练习的进度和历史会自动保存。测验点「错题重练」可重做最近答错的题，闪卡点「待巩固重练」可复习最近标记为需要再练的卡。闪卡按你的自评记录，测验按生成时保存的答案判分。如果调整来源后提示练习已过期，请重新生成练习。之前的作答记录仍然可以查看。

## 管理笔记本和会话

- 点顶部的笔记本名称可以切换或重命名笔记本。点「会话」回到之前的工作台对话，点「新对话」开启一条独立会话。
- 想在 DSH 普通对话中使用同一本笔记本时，先打开那条普通对话，再从工作台的「更多操作」中选「关联当前对话」。之后可以在普通对话里请模型查看来源、整理材料或生成 Studio 内容。
- 在窄窗口，用顶部的「来源」「对话」「Studio」切换区域。想腾出阅读空间，可以在「更多操作」中选「专注阅读」。同一个菜单也可以关闭或开启动效。

## 数据、备份和卸载

笔记本、来源、Studio 内容、工作台消息和练习进度保存在当前 profile 的 `plugin-data/dsh-notebook/library.sqlite`。例如，个人桌面 profile 的默认路径是 `~/.dsh/profiles/desktop/plugin-data/dsh-notebook/library.sqlite`。插件配置了 `dataDir` 时，资料库在指定目录下。

资料问答和 Studio 会把相关资料片段交给你选中的模型处理，网页检索与读取走 DSH 中配置的服务。工作台完整的模型会话还依赖 DSH 保存的原生会话日志。迁移或备份时，先退出 DSH，再复制完整的 profile。自定义过 `dataDir` 时也要备份该目录。

想卸载插件时，先退出 DSH，再运行下面的命令。资料库保留在原来的目录。

```sh
dsh plugin --profile desktop remove @lks347/dsh-notebook
```

## 常见问题

- **侧栏没有「笔记本」**。检查安装命令中的 profile 是否和正在运行的 DSH 一致，确认插件已经启用，然后完全退出并重新打开 DSH。可以用 `dsh plugin --profile desktop list --depth 0` 核对安装的包和版本。
- **没有可选模型，或者提示需要登录**。先在 DSH 里登录并检查模型提供方，再回工作台点「刷新模型」或「重试」。
- **「开始检索并构建」不可用**。确认研究目标已填写，并在 DSH 配好可用的网页搜索、网页读取和模型。已有资料也可以用「添加来源」直接导入。
- **发送或生成按钮是灰色的**。先打开笔记本、勾选至少一个可用来源并选择模型。如果已有任务在运行，可以等它完成，或从输入框旁停止。
- **回答太慢或提示上下文不足**。可以缩小问题范围、减少本轮勾选的来源，或选择上下文更大的模型。默认的搜集构建预算是 15 分钟、48 步，资料问答是 3 分钟、24 步，学习导读和单次 Studio 生成各有独立的 3 分钟预算。

遇到安装或使用问题，提交时可以附上 DSH 版本、插件版本、复现步骤和界面上的错误提示。[提交问题](https://github.com/lakeofsky347/dsh-notebook/issues)

## 开发

```sh
npm ci --legacy-peer-deps
npm test
npm run dev
npm run test:ui
```

开发预览使用本地模拟宿主和模型，默认地址为 `http://127.0.0.1:8765/dev/preview.html`。浏览器检查需要 Chrome 或 Chromium，可用 `CHROME_BIN` 指定路径。

# DSH Notebook 助学 Agent 调研与优化建议

调研日期：2026-11-16（Asia/Singapore）。对象为已有产品和维护中的开源项目；主要依据官方帮助、项目文档及研究原文。本文是产品设计建议，不代表下列功能已经在 DSH Notebook 实现，也不代表已经复现外部产品的学习效果。

## 当前判断

DSH Notebook 已有研究工作台所需的主要基础：SQLite 资料库、来源选择、中文 BM25 检索、工作台模型会话、来源引用、可停止的 Agent、七种 Studio 产物。当前最值得补齐的是两个连续流程：**研究需求 → 可核查资料库 → 有依据的导读**，以及 **学习目标 → 学生作答 → 解释反馈 → 独立再测**。

调研时读取的本地基线包括 `README.md`、`src/prompt.js`、`src/service.js`、`src/library.js` 和 `src/workbench.js`。原有研究模式主要由 Agent 提示词协调 `web_search`、`web_fetch` 和 `notebook_add_source`；闪卡与测验仍以 JSON 预览为主，提示词没有稳定题目 ID、知识点、证据定位或评分约定。该描述对应本次改动开始时的基线，后续代码修改以实现和测试为准。

## 值得借鉴的现有方案

| 方案 | 已有能力与适用场景 | 对本项目的启发 | 证据边界 |
| --- | --- | --- | --- |
| Gemini Notebook / NotebookLM | 快速与深入研究、搜索结果及报告导入；在选中来源内问答并定位引用；交互式闪卡、测验和 Learning Guide。适合围绕一组资料研究与学习。 | 把检索、导入、引用、学习产物做成连续工作流；明确候选来源与已入库正文的差别。 | 官方帮助证明产品能力，不能直接证明学习成绩提升；功能存在账号、平台与额度限制。[研究与导入](https://support.google.com/gemininotebook/answer/16215270?hl=en)、[资料问答](https://support.google.com/gemininotebook/answer/16179559?hl=en)、[闪卡与测验](https://support.google.com/gemininotebook/answer/16958963?hl=en) |
| Khanmigo | 围绕练习提供辅导，并利用近期做题记录和前置技能信息调整教学；官方持续做产品实验。 | 建立结构化学习状态，使用“接受辅导后独立完成下一题”评价帮助是否有效；避免把对话长度当学习进步。 | 官方产品实验报告不是所有学科的普适结论。记录不同实验的收益时不直接相加为本项目预期效果。[官方产品研究](https://blog.khanacademy.org/how-khan-academy-is-building-a-better-ai-tutor-our-most-recent-learnings/) |
| Gemini Guided Learning / LearnLM | 通过开放问题、分步讲解和多模态材料引导参与；LearnLM 是教育模型能力，Guided Learning 是面向用户的产品交互。 | 助学模式需要根据学生答案调整下一步；为“提示、例子、完整讲解”保留明确入口。 | 产品介绍与模型评估不能替代实际教学试验，也不能推断给任意模型加提示词即可达到相同效果。[官方介绍](https://blog.google/products-and-platforms/products/education/guided-learning/) |
| Open Notebook | 维护中的自托管研究工具；支持来源、笔记、可复用 Transformation、文本与向量检索，以及分阶段 Ask。 | 来源加工模板、分阶段进度、按角色选择模型可借鉴；搜索与资料入库能力适合复用现有宿主。 | 是工程参考，不是已证实有效的助学系统；其文档明确引用定位到整个条目，引用存在并不保证正确。[核心概念](https://github.com/lfnovo/open-notebook/blob/main/docs/2-CORE-CONCEPTS/index.md)、[搜索](https://github.com/lfnovo/open-notebook/blob/main/docs/3-USER-GUIDE/search.md)、[引用限制](https://github.com/lfnovo/open-notebook/blob/main/docs/3-USER-GUIDE/citations.md) |

与模型研究相关的一项直接证据是 LearnLM 与 Eedi 的探索性随机试验：165 名英国中学生、五所学校，AI 生成的消息受到专业导师逐条监督并可修改。研究支持在该设置继续探索 AI 辅导，不能推导为无人监督 Agent 在大学课程、中文材料或本地 DSH 模型上同样有效。[研究原文，2025-12-29](https://arxiv.org/abs/2512.23633)

## 建议优先级

以下优先级和验收指标是针对本项目的设计判断，不是外部产品的性能承诺。

| 优先级 | 改进 | 具体落点 | 如何验收 |
| --- | --- | --- | --- |
| P0 | 自动建库成为可恢复任务 | 输入研究目标、可选来源数与范围；自动拟检索方向、调用 DSH 搜索、获取正文、去重入库、生成导读；持久化步骤及每条来源结果。 | 用户一次提交后得到真实笔记本；来源与任务绑定；超时、取消、部分失败仍可查看已保存内容。 |
| P0 | 建立证据分层与来源追踪 | 搜索摘要标成候选，正文导入成功后才算可引用资料；保存原始 URL、获取时间、正文提取状态和查询来源；生成笔记保留其派生来源。 | 搜索摘要不会冒充全文；导读引用只能落到当前库真实来源；失败页面不计入成功数。 |
| P0 | 研究结束交付可用的学习入口 | 自动保存主题范围、核心问题、阅读顺序、分歧与资料缺口；有需要再生成学习指南或测验，避免默认批量生成全部产物。 | 建库完成即有可读导览；对缺失资料明确说明；已有来源可直接进入资料问答。 |
| P1 | 加入引导学习模式 | 与资料问答并列。先确认目标或用一题判断基础；一轮聚焦一个概念；依据学生作答给予提示、短例子、追问或完整解释。用户可直接选择讲解深度。 | 连续对话能利用用户上一答；答错时能指出具体误解并回链资料；用户要求完整讲解时可切换。 |
| P1 | 让测验与闪卡真正可练习 | 将纯 JSON 改为答题/翻卡界面；题目有 `id`、`conceptIds`、难度、选项、标准答案、解释、`sourceIds`；先保存作答再揭示解释；支持错题重练。 | 答案揭示前已记录作答；重开仍保留进度；无效题目或引用不会作为完成产物展示。 |
| P1 | 将整篇来源引用细化到证据片段 | 复用现有 chunk ordinal、locator 和 source revision，记录问题及产物引用的片段；点击引用显示支持文本和上下文。生成笔记不自动成为独立外部证据。 | 能从答案找到支持原句；来源更新后标记旧产物；跨笔记本来源 ID 被拒绝。 |
| P2 | 建立保守的学习状态与复习队列 | 保存知识点、尝试次数、独立正确、使用提示、错误类型、最近练习和自报信心。先用透明规则安排复习，数据充分后再考虑知识追踪模型。 | “看过解释”不记为掌握；提示辅助正确与独立正确分开；学习记录可查看、重置和删除。 |
| P2 | 用实际任务评估检索和教学 | 建立含中文、英文、来源冲突、无答案、网页失败的固定任务集；将检索、引用、学习结果、成本与等待时间分别测量。 | 对照改动前版本，报告检索覆盖、来源有效率、引用支持率、独立再测正确率；保留失败案例。 |

检索路线建议先优化多查询拆分、去重、来源选择与 BM25 的查询扩展。向量检索适合作为经过评测的补充；增加 embedding 本身不能证明答案质量提高。Open Notebook 的文档也区分了全文语境与检索命中的局部语境，这对长教材和跨段推理尤其有参考价值。[Open Notebook 搜索与 Ask](https://github.com/lfnovo/open-notebook/blob/main/docs/3-USER-GUIDE/search.md)

教学评估建议同时记录独立作答与提示依赖。Khanmigo 的官方研究把下一题独立正确率、认知参与和响应延迟分别衡量，并监控提前泄露答案及数学错误；这比仅统计生成多少份学习资料更适合评价本项目。[Khanmigo 评价方法](https://blog.khanacademy.org/how-khan-academy-is-building-a-better-ai-tutor-our-most-recent-learnings/)

## 分阶段落地范围

**当前一轮：** 完成 DSH 搜索到自动建库，保持宿主模型、凭据和权限路径；补上可观察进度、正文保存、重复来源处理、失败说明和有引用的导读。可以在学习指南中加入自测与“资料不足”提示，但不把生成一份指南称为已经实现自适应学习。

**下一轮：** 完成交互测验、闪卡和引导学习。用持久化作答记录建立学习状态的数据基础；为数学、代码等可验证任务考虑确定性检查器，工具路由与超时要可见。

**再下一轮：** 评估知识点图、间隔复习、可选语义检索，以及 PDF / 讲义解析。音频讲解、视频和丰富视觉产物可按实际学习需求加入；应先确认资料准确和学习流程可用。

## 限制与复核方式

- 本次未登录或付费实测这些外部产品，也未运行其代码；能力判断来自官方页面和维护者文档。
- 官方产品帮助是功能依据，官方产品实验属于提供方报告；本文单独标明了实验规模和人工监督，未将其泛化为自动化 Agent 的能力。
- 没有比较各方案的长期保持效果、中文课程表现或用户个人学习成绩；这些需要后续实测。
- 外部文档和本地实现都可能继续变化。开发验收需以当前代码、真实 DSH 运行记录和可复查来源为准。

## 本轮实现范围

| 能力 | 当前实现 |
| --- | --- |
| 可执行的练习产物 | Studio 测验与闪卡生成版本化 JSON。测验包含题目、选项、正确选项、解释及来源 ID；闪卡包含正面、背面、解释及来源 ID。生成完成前校验结构和来源归属；不合格产物标记失败，不把无法评分的内容记为成功。 |
| 选择题作答 | 逐题选择后提交，由本地规则对照产物的正确选项评分。提交前的公开题目状态不含答案和解释；提交后展示反馈与可点击来源。评分不是额外请求模型判断。 |
| 闪卡回忆与自评 | 先尝试回忆，再提交回忆并翻面；想不起来时允许空白回忆。显示答案后自评“记住了”或“再练一次”。自评与测验正确率分别呈现，不将自评等同于客观掌握度。 |
| 保存与继续 | SQLite 保存练习会话、当前位置、已提交答案、评分和请求记录。重开可恢复进行中或已完成会话；完整练习与错题重练分开记录。 |
| 错题与待巩固 | 依据同一产物各题最近一次已评分结果形成队列；重练答对或自评记住后移出。只翻面而未自评，不当作已经掌握。原先错误记录保留在历史中。 |
| 历史、引用与隔离 | 可展开查看已提交历史；解释引用仅打开当前笔记本已保存来源。练习绑定当前工作台的笔记本，宿主会话 ID 与练习会话 ID 分开。切换笔记本时清理当前练习界面。 |
| 重复操作与版本变化 | 提交请求去重；延迟或重复的“下一题”不跳过新题。来源或产物修订改变后，保留历史并阻止沿用旧版本继续评分，引导重新生成。 |

API 为 `studyOpen`、`studyGet`、`studyAnswer`、`studyRate`、`studyNext`，统一返回练习状态。当前版本没有实现长期学习者画像、间隔重复排程、开放题语义评分或学习效果评估；本轮验收也不对这些能力作承诺。

模拟 UI 已实际点击验证以下闭环：

- 测验选错 → 保存 → 查看解释引用 → 返回恢复 → 下一题 → 关闭重开 → 完成 → 只重练错题 → 答对后移出队列，原错误历史保留。
- 闪卡先提交回忆 → 翻面 → 自评再练 → 完成原队列 → 重练并自评记住 → 清空待巩固项 → 关闭重开仍可查看历史。

- 无效 JSON 和未知来源引用明确拒绝并提供重新生成入口；解释中的 HTML/脚本仅显示为文字。

模拟 UI 的“关闭重开”是同页关闭详情、引用往返和笔记本切换恢复；它不是整个 DSH 应用重启后的持久化证明。SQLite 恢复的自动化验证与真实宿主重启验收需要分别陈述。
